# 识别结果与旧操作

识别成功后，新事项直接存入工作区。新任务保留可确定的时间和原文。通知、延期、更新和取消以通知呈现。用户可以在详情里选择已有任务，进入普通编辑器并自行保存修改。

来源记录与工作区写入在同一事务中提交。任务的 `recognitionHistory.storageId` 关联来源和历史回执。已处理的识别结果不会因为重新读取或重启而再次加入。

升级时，未归档的真实识别批次中尚未处理的记录会转入清单。已忽略的记录保留原决定。客户端历史操作继续使用原请求身份和版本校验，通过 `POST /api/recognition/candidates/{id}/resolve` 重放。已被迁移的记录与尚未送达的旧编辑发生冲突时，保留本地操作并提示重新读取。撤销旧版忽略操作会将该记录作为普通任务或通知加入清单。
