# 识别结果与旧操作

识别成功后，新事项直接存入工作区。新任务保留可确定的时间和原文。通知、延期、更新和取消以通知呈现。用户可以在详情里选择已有任务，进入普通编辑器并自行保存修改。

来源记录与工作区写入在同一事务中提交。任务的 `recognitionHistory.storageId` 关联来源和历史回执。已处理的识别结果不会因为重新读取或重启而再次加入。

升级前请备份数据库。升级只把未归档、非演示批次里明确的新任务补入清单，要求识别时无需复核、有明确截止且尚未过期。日期按来源时区保留到当日结束，带时刻的截止按实际瞬间比较。教学网还须属于当前账号的有效快照，并通过原生提交状态保护。其余旧条目在数据库保留原文、识别结果和迁移原因 `legacy_history_only`。这一标记与用户主动忽略分开。已关联的任务（含已完成或在回收站的任务）沿用已有记录。再次启动不会重复新增。新导入仍可直接保存无截止任务、活动和通知。

客户端历史操作继续使用原请求身份和版本校验，通过 `POST /api/recognition/candidates/{id}/resolve` 重放。已被迁移的记录与尚未送达的旧编辑发生冲突时，保留本地操作并提示重新读取。撤销旧版忽略操作会将该记录作为普通任务或通知加入清单。
