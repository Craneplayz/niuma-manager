## 重复功能与未采纳部分

- **账号和数据**：保留现有邮箱登录、SQLite、HttpOnly 会话和版本冲突机制；不合入访客 localStorage、浏览器计时存储或另一套后端。
- **识别审核**：保留 v0.2 的来源证据、日期可信度及事务确认；参考版本的聊天草稿与本地日期规则不替代统一协议。
- **模型规划**：保留用户主动开始、模型估时、预览确认和已有安排约束；不合入固定模板拆解、默认一小时、规则倒排、规则风险评分或 What-if 排程，避免与“完全交由模型评估”的要求冲突。
- **语音**：暂不接入。浏览器语音或云端转写涉及权限、第三方传输与新的接口，需要后端/Harness 共同约定；现有文字入口可用。
- **学习洞察、连续完成与估时准确度**：暂不合入参考算法，其结果依赖完整完成时间和实际投入记录，不能用计时结束或缺省工时假定真实投入。
- **撤销删除、依赖与负责人、深色主题**：此次保留原有任务操作和视觉体系，不直接搬入与当前数据模型和事务语义不一致的机制。课程暂不提供删除、独立多资料列表或课程 ID 外键迁移。
- **外部日历**：仅文件导出，不声明账号授权、自动导入或双向同步；JSON 暂不支持恢复导入。

## 目录与验收

所有前端源码、Node 配置、前端测试及本说明集中于 `frontend/`。`server/` 为配套本地后端，根目录 `docs/` 为共享协作协议，项目 README 保留团队内容并只增加前端入口。

在 `frontend/` 运行 `npm test`（11 项 Node 测试 + 25 项本地 API/Python 测试）及 `npm run build`。新测试覆盖任务筛选、计时计算、ICS 时间与转义/折行、课程与计时的数据隔离、版本冲突和非法输入。

真实模型、语音、实体手机与外部日历客户端导入效果不由这些本地测试替代。
