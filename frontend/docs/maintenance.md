# 前端维护指南

## 模块边界

- 页面、样式、浏览器交互和 API 适配位于 `frontend/src/`。
- 网页通过同源 `/api` 调用业务后端；Vite 开发代理指向 `127.0.0.1:1332`。
- 文本识别和规划由服务端 Harness 执行，浏览器不执行 `SKILL.md`，也不保存模型密钥。
- 共享数据格式由团队契约维护；前端只负责展示、确认和状态映射。

## 维护要求

1. 按 [CONTRIBUTING.md](../../CONTRIBUTING.md) 从当前 Issue 指定的基线建立分支。
2. 前端变更保持在 `frontend/`；跨模块修改交由对应负责人审查。
3. 保留现有源码路径和样式加载顺序，避免破坏测试及并行开发。
4. 运行 `npm test` 和 `npm run build`；界面变更同时检查桌面与移动端。
5. 不提交依赖、构建产物、日志、数据库、密钥或本地配置。

## 文档规则

`README.md` 保留目录、启动和验证入口。当前专题文档放在 `docs/`；已失效但仍需追溯的文档按日期移入 `docs/archive/`。
