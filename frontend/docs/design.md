# 当前界面规格

## 产品范围

主界面突出任务内容，功能入口集中且容易点击。两条主要路径是“导入通知”和“查看、处理任务”；不在主页面增加统计卡片、宣传文案或其他工作台。

导入来源包括文本、教学网和图片与文件。邮箱保留显式禁用入口，尚未接入。任务支持新增、编辑、完成、重新打开、删除到回收站和恢复；账号位于侧栏底部。当前不提供学习规划、任务拆分、时段安排或计时功能。

真实数据属于登录账号并保存到服务端。`demo=1` 只展示合成任务：操作留在页面内存，刷新重置，文本和任务不发送到识别、采集或账号保存接口。视图偏好可以保存在浏览器，公开环境信息可以读取。

## 视觉原则

系统错误说明面向普通用户，说明未完成的操作和用户可执行的下一步，不要求安装依赖、配置模型或理解协议。统一错误区提供“反馈此问题”，仅点击后提交受限分类、操作、时间和版本，显示提交中、已提交或可重试的失败；未知错误保留通用提示和反馈入口。普通输入校验直接提示更正，不作为系统错误上报。弹窗中的错误与反馈按钮必须在弹窗内可操作，不用短暂消失的提示替代；反馈不得清空编辑内容。服务器不可用时如实显示未能确认提交。

通知使用独立入口、浅灰标签和日历中的灰色卡片。列表左侧与详情底部都可勾选“已阅读”，取消勾选恢复未阅读，两处状态同步。读取既有 `content_type`；阅读状态复用任务状态，通知的 completed / done 表示已阅读，其他可见状态表示未阅读，不新增接口字段或执行历史数据迁移。

界面采用克制的卡通风格：内容与侧栏保持纯白，沿用清楚的文字层级和留白，以细描边、圆润控件和少量牛马形象建立辨识度。主按钮使用柔和珊瑚桃色与深棕文字，导航、视图开关和账号入口悬停使用同一浅桃色；日期保留雾蓝，错误、逾期、待核对和恢复结果沿用各自语义颜色。

60 / 30 / 10 是面积与视觉权重的指导：主要内容约占六成，功能区域和次层信息约占三成，关键操作与选中态约占一成。它不要求给三块区域分别涂满颜色，也不要求强行增加蓝色面积；先保证内容、导航、操作的层级，再按实际页面调整留白。

| 层级 | 表现 |
| --- | --- |
| 主要内容 | 白色任务区域，最清晰的正文对比与主要阅读空间 |
| 功能区域 | 白色侧栏、细分隔线和少量中性控件底色，导航和任务内容明确分开 |
| 主操作 | 珊瑚桃色按钮、深棕文字、简短动词和可识别图标；停止导入保持深色白字 |
| 选中与日期 | 导航与视图开关使用浅桃色，日期保留雾蓝，使用形状与字重共同区分 |
| 辅助信息 | 中灰文字，字号降低但保持清楚可读 |

桌面页面标题为 29px，导入与任务复用紧凑标题组件。各页统一移除“我的任务 / 通知 / 导入”等浅色辅助标注及其独立占位行，让正式标题与正文整体上移。日期与标题同处首行右侧；有“添加任务”入口时，按钮位于日期左侧，间隔 16px，二者整体靠右。任务名称约 17–18px、当日面板任务约 15px、课程和来源约 11–12px。层级同时依靠字号、字重、位置和留白；不以浅到难读的颜色区分信息。任务名称允许自然换行，避免为了容纳冗长标签压缩正文。

按钮和输入控件沿用 12px 主圆角与细边框，主按钮的深棕文字保持清楚对比；清单、日历、导入、详情、账号和独立后台共用主题颜色与控件层级。任务保持平铺，日期分组以细线分隔，正文区域保留完整阅读空间。

品牌图采用单体扫描牛：右上为空心勾选牛角，下方是单点与直线进度嘴，扫描框仅保留左上与右下两个对角。普通应用、后台顶栏与后台登录使用同一 `brand-logo.webp`，标签页图标由 `favicon.svg` 嵌入该图生成；仅裁去多余白边并缩小，不重绘形象。

主界面品牌图显示为 36×32px，窄桌面侧栏使用 32×28px；展开侧栏底部保留 156×84px 探头形象。图片预留固定尺寸，不独立接收指针或键盘焦点。折叠侧栏隐藏品牌图与底部插画；700px 及以下手机宽度或 720px 及以下窗口高度隐藏底部插画，优先保留导航和账号入口。

`theme.css` 统一维护品牌深棕 `#4a291c`、主操作珊瑚桃 `#f2a18a`、悬停 `#eb957e`、按下 `#e48970`、浅底 `#fff1ec` 与边框 `#f0d1c7`；操作文字使用 `#9c4935`，焦点轮廓使用 `#a44f3a`。正文、中性分隔线与语义色沿用原有层级。

## 布局与入口

- 桌面固定收放按钮切换 232px 侧栏与 72px 图标栏；折叠后可直接点击导入、全部任务、通知、临近截止、已完成和账号，悬停约 500ms 或键盘聚焦时显示名称。导入为明显主入口，任务范围位于同一区域，账号固定底部。
- 所有页面位于 `app.js` 统一的 `.page-frame` 内，最大宽度 1450px；共用标题栏包含正式标题、视图切换、操作和日期，清单与日历切换时标题位置保持一致，日历省略查询行以留出阅读空间。
- 清单与日历使用 `.page-frame` 内可用宽度，导入正文使用最大宽度 860px、左对齐的 `.page-reading`；后续页面共用 `workspaceHeading` 提供的导航与日期，并通过 `renderPageHeading` 和 `.page-frame` 统一布局，仅在内部调整阅读区或宽视图。
- 任务详情采用约 420px 的右侧抽屉，背景清单和查询状态保留。
- 700px 为手机布局断点：侧栏保持可关闭的抽屉菜单，不使用桌面图标栏；首行左侧保留导航触发按钮，右侧排列添加按钮与日期，间隔 12px。正式标题与视图切换在次行，任务抽屉适配窄屏。
- 关键触控操作提供至少 44px 有效点击高度。选中状态除了颜色，还使用字重、形状及 `aria-pressed` 或 `aria-current`。

“清单 / 日历”双段开关放在全部任务标题右侧，删除独立标签栏；临近截止与已完成固定使用清单。“月 / 周”只出现在日历内部，避免把所有视图放进侧栏。日期选择和查询控件不与导入入口争夺视觉重点。

## 任务查询与清单

侧栏依次提供全部任务、通知、临近截止、已完成。全部任务清单显示未完成任务；通知清单保留有日期和无日期、未阅读和已阅读的通知，已阅读项保持勾选，方便直接取消。临近截止包含逾期和今天起未来 7 天的未完成任务及未阅读通知；已完成混合展示已完成任务和已阅读通知，相应计数包含两类内容。通知使用浅灰“通知”标签和阅读勾选，关键时间与任务截止分开表述；沿用查询、详情、编辑、回收站和撤销操作。

任务清单按以下顺序分组，空组不显示：已逾期、今天截止、明天截止、未来 7 天、之后截止、无截止日期。任务与通知混合时使用“早于今天”“今天”“明天”等日期表述，未阅读通知的过去关键日期与任务共用红色日期样式，已阅读后恢复普通颜色。通知清单与已完成清单平铺，已阅读通知不使用任务的删除线。

通知清单优先显示未阅读通知，已阅读通知放在下方；同一阅读状态内按关键时间从早到晚排列：先比较日期，同一天按具体时刻升序，仅有日期的通知排在当天有时刻的通知之后；无有效日期的通知放在最后。相同时间按稳定 ID 排序；搜索、筛选和更新阅读状态后继续沿用此规则。排序只作用于前端展示，不改写服务端数据顺序。

清单查询区常驻关键词、课程和筛选入口，来源与截止日期范围收在可展开筛选区，组合条件一起生效。切换到日历时不绘制查询及高级筛选区，也不应用清单条件，防止隐藏筛选造成日程缺漏；切回清单恢复原查询条件。完成任务或关闭详情保留查询、选中日期和浏览范围；从日历进入临近截止或已完成，再返回全部任务时，恢复原月份、日期、月周模式与视图偏好。

任务行的完成按钮与详情按钮相互独立，不能嵌套按钮。名称是视觉主体，课程、来源与进行中状态退到辅助层；截止日期在清楚的位置显示。查看详情后可编辑任务、标记完成或删除。

课程使用 8 个固定柔和色系，清单和当日面板将课程名显示为“同色圆点＋浅底课程签”，详情复用同一课程签，已选课程筛选旁显示同色点；未填写课程时使用中性灰“未分类”。任务标题保持深色，来源仍为辅助灰字；课程名始终保留，长名可截断但完整名称可查看，避免只靠颜色区分。

配色依据规范化课程名识别，已有课程保持原色，新课程优先使用空余色；超过 8 门允许复用色系。浏览器按账号范围保存课程名哈希和色号的视觉偏好，不保存课程名原文或任务；存储不可用时继续显示可用配色，不阻断任务操作。更名后的课程按新名称识别；当前不增加选色设置或自定义筛选器。课程色与逾期红、待核对黄等状态色各自表达含义，不改变日期雾蓝和页面白底。

## 完成伙伴

用户手动完成任务且保存成功后，底部出现一只牛马伙伴及一句短话，牛牛真诚肯定，马马先认可再轻松提醒下一项；两者轮换，连续完成合并为一次反馈，不排队播放。没有未完成任务时改为收工文案，剩余数量包含未显示的待核对任务，排除通知、回收站与已取消任务；不推测任务难度或耗时。

图案与文字位于同一小提示中，保持白底、深棕文字和克制的桃色细节，保留关闭与撤销，连续完成明确仅撤销最近一项。只读详情内的反馈与撤销保持可操作，编辑表单和账号窗口优先；反馈不移动键盘焦点，状态以礼貌播报提供。通知阅读、重新打开任务、自动同步和失败保存不触发庆祝。

每次只播放一次短动作，然后静止，禁止循环蹦跳或声音；系统减少动态或关闭小动画时保留静态角色与文字。账号内提供“完成时显示牛马伙伴”和“播放伙伴小动画”，偏好仅保存在当前浏览器，关闭伙伴仍沿用普通完成提示与撤销。

## 月历与周历

日历仅属于全部任务页，展示未完成任务的**截止日期**及通知的**关键时间**，不表示执行时段或学习计划；已完成任务不进入日历。通知以灰色卡片和“通知”标签区分，不额外展示类型图例或通知总数，通知不计入任务总数。具体时刻可以展示；未提供时刻时不补造 23:59。

月历周一开头，按月份显示 4–6 行并淡化相邻月份日期，按标题与月份工具栏下方的可用窗口高度等分行高，优先在首屏展示完整月份。桌面鼠标操作时日期条为 32px、日期圆形区域为 24px，给任务摘要让出空间，并相应放宽摘要显示门槛；手机与触屏保留至少 44px 点击高度，周历沿用原布局。每格空间充足时最多显示两条任务摘要，更多任务用“+N 项”进入当天清单；行高变小时显示首条摘要与当天总数，更小时只显示日期和总数，点击日期始终可查看全部内容。今天和选中日期以轻背景或小圆区分，桌面摘要可直接打开任务详情。极矮窗口允许自然滚动，不裁掉日期或任务。

周视图按周一至周日列出截止任务，不使用小时网格。月、周支持前后导航、返回今天及指定日期跳转；月份和周范围正确跨年。进入周视图应围绕当前选中日期展示，避免日历与当日面板指向不同时间。

月历与周历任务摘要使用同色圆点和课程简称，完整课程名在提示与辅助阅读名称中保留。宽屏当日任务在日历右侧独立滚动，窄屏在完整月历下方。无日期任务有明确入口，不塞进任何日期格。手机月历隐藏长标题，保留日期、任务数量与最多 3 个去重课程色点，点击后在下方阅读完整课程签和清单；手机周视图改为按天的单列列表，避免横向滚动。

月、周视图的日期格、当日任务和“无日期”面板均支持拖动未完成任务和未阅读通知；单击仍打开详情；鼠标主键按住任务名称并移动至少 6px 后才开始拖动，不新增设置日期按钮。拖动预览按任务文字中的抓取位置贴住鼠标，指针覆盖文字，不再向右下偏移；从课程、来源等辅助区域起拖时使用文字中心。整格日期都可接收任务，悬停高亮并预告目标截止日期；松开后设置或更改截止日期，无日期任务按日期精度保存，已有日期的任务保留原时刻；拖回原日期不重复保存。保存成功后任务移入目标日期格并选中该日，保留当前面板以便继续整理，并提供 7 秒撤销；失败时任务留在原位，失败的拖放不会随其他保存再次提交，版本冲突须重新读取。拖到日期外、Esc、指针取消、失焦或页面重绘均取消操作，拖放结束不触发详情。通知沿用相同拖动、保留时刻及撤销逻辑，提示称为关键日期；已完成任务、已阅读通知不可拖动，触屏滚动沿用现有行为；键盘与手机可通过原有详情编辑日期。

编辑过程中如果任务内容被更新或移除，保存时保留草稿并提示重新核对；临时保存失败后可再次保存。删除或恢复失败后，“重试保存”会重试原操作并同步任务与回收站列表。

## 导入与核对

文本页只保留通知输入、可展开的通知时间和识别按钮。教学网页保留连接状态和连接管理，同一操作区选择单次、定时频率或自定义间隔，并使用一个主按钮启动识别或停止定时同步；仅在选择待启动的定时频率后展示明确授权。邮箱入口禁用并明确说明尚未接入。

教学网使用持久化后台采集与识别，进度变化后刷新任务和候选，离开或刷新网页后可恢复；明确任务由后端直接保存，需核对的结果保持手动，前端不再循环调用识别及自动加入。运行时原位主按钮变为带方形停止图标的黑底白字“停止导入”，启用定时服务时显示“停止同步”；停止请求期间显示禁用的“正在停止…”，失败后恢复停止操作并显示错误。运行时在同一个停止按钮内，用沿小方形四周循环移动的短线表示当前正在采集或识别；中心停止方块静止，与外侧线条留约 2px 间隙，轨迹略带圆角，每 1.6 秒循环一次；点击按钮仍停止，停止请求期间保留动效并禁用按钮。定时服务等待下一轮时恢复静态停止图标，结束或失败后不再移动；读取进度本身不触发动效。阶段和已处理数量放在按钮的悬停提示及屏幕阅读器状态中，移除独立的运行状态行和直线进度条。仅在已有新增、待核对、更新或错误时，继续在操作区下方显示真实结果；没有结果不留空行。减少动态效果设置下显示静态短线，停止功能不变。停止先关闭定时服务，再通过后端接口阻止当前运行的后续派发及迟到结果入库，保留已经保存的任务；关闭定时失败仍尝试停止当前运行并明确提示。历史只提供一个“处理未完成”入口，按最新尝试处理本轮尚未恢复的异常；仅识别失败时直接重试，含来源缺失时仅重新获取并处理异常来源。成功项、正常待核对项及无关新内容不重复处理；错误详情仍可“处理本条”。补齐后成功的旧异常标为已恢复，来源仍缺失则继续保留异常。历史只保留新增任务或通知、待核对、已有任务实际更新及错误，同一来源的同类错误仅显示最新一次，已恢复异常保留最新一条并显示灰色状态，混合记录保留真实产出，移除单独的“处理详情”，点击“错误 / 待核对 / 新增 / 修改”数量展开对应名称列表，零数量不显示；普通浏览每轮只展开一类，再点当前分类收起；恢复定位可临时同时展开全部关联分类。桌面采用两至三列紧凑排列，手机按宽度缩为一至两列，无逐行卡片或分隔线；长名称单行省略、悬停显示完整名称。新增与更新直接打开既有任务或通知详情，待核对打开既有核对窗口；错误先列来源名称，点击再显示原因与恢复入口。列表按真实任务和候选身份逐项展示，一条来源拆出多个任务时分别列出；更新附实际变化字段的简短说明，旧记录仅在身份和数量能核实时补齐名称。重复、跳过、过滤和无任务结果不显示，空停止记录也不占位。定时检查无变化时不进入历史，只更新“上次检查”；手动检查无变化时临时提示“已检查，没有新内容”。失败重试后不产生任务时，原错误仍标为已恢复，不能继续重试已完成的内容。历史与各轮分类默认折叠，切换分类和轮询保留选择，避免挤占核对区。

分类标签只显示名称和历史数量，标签文字统一以红、黄、绿表示当前处理状态，不追加“全部已恢复 / 部分已恢复”文字。错误全未恢复为红色、部分恢复为黄色、全部恢复为绿色；待核对有未处理项为黄色，全部确认或忽略后为绿色，旧回执无法确认核对状态时保持黄色。新增与修改代表实际保存结果，显示绿色；任务本身未完成不算导入错误。恢复和核对进度在悬停提示及辅助阅读说明中提供，历史数量不因处理完成而清零。单条已恢复状态及跳转链接仍为灰色。

分类按当前处理优先级排序：未解决错误、仍待核对、新增、修改、已处理的核对记录、已恢复错误。没有对应分类时省略；错误全部恢复后移至最后，核对全部处理后移至新增和修改之后。排序变化保留当前展开分类和按钮身份，不主动切换列表。该规则同时用于同步与独立识别历史。无逐条记录的整轮采集失败，在同一牛马账号及同来源范围的后续完整采集成功（允许修正密码或更换教学网账号）后也标为已恢复，撤去过时提示及处理入口；无变化检查同样有效，仅模型重试或局部补采不能证明整轮采集恢复。

点击灰色“已恢复”时，沿恢复链接展开全部关联批次及其新增、待核对、修改分类，将第一处关联批次的完整标题滚动到可视区域顶部并留 24px 间距；所有关联条目使用浅色背景和蓝灰色左边线高亮，保留原状态颜色，不追加箭头或文字标记。靠近页尾时临时补足滚动空间；高亮在滚动、键盘浏览及重绘后保留，切换分类、查看其他恢复记录、收起历史或离开导入页时清除。读取期间的后续操作仍取消迟到定位，整轮恢复包括首次成功采集的全部产出及后续分批重试结果；旧记录缺少具体名称或没有产出时定位并高亮批次标题；目标不在最近 20 条时读取单批次；对应记录不存在时提示“对应的恢复记录已无法查看，已保存的任务不受影响”，读取暂时失败时提示稍后重试。

文本识别仍使用当前页面请求，“停止导入”取消等待及后续前端处理；点击后说明后台已开始的识别可能继续，按钮旁不常驻说明。自动同步使用 source-sync/0.1 的现有接口；频率选择提供单次、常用间隔与 15～10080 分钟自定义间隔，定时启动时须明确同意定期获取与识别教学网内容，并立即识别一次；切回单次会先关闭已有定时服务。点击停止同步后保留当前选中的频率及自定义分钟数，按钮回到待启动状态；重新启动沿用既有明确授权流程。未连接账号、服务未开放或保存冲突均提供对应状态。前端不提供任务排程入口。

图片与文件使用单一文件选择区，文件名、大小、移除操作及上传同意只在选择后出现；支持 PNG/JPEG/PDF/DOCX。正在处理和失败的记录可见，成功记录收在“最近导入”，候选使用共用核对区，不重复展示在文件记录中。失败提示使用用户能理解的原因和下一步，不显示内部平台、适配器或模型协议字段。

教学网页不再提供“作业与提交状态”手动目录和管理弹窗；后台原生提交识别、已有提交关联及自动完成逻辑保留。

核对区只展示待核对候选，保留识别摘录、可展开的完整原文和安全来源链接；已忽略内容折叠并可撤回，已处理候选不重复展示。失败及来源待补全通知在导入进度与历史导入中查看；当前来源只有一个历史入口，未关联后台运行的独立识别结果按真实 importId 归为批次，一并展示新增、待核对、更新和错误；错误点击名称后查看原因与反馈，重试只针对该批次未完成的识别。同步已接管的记录即使被去重、恢复或移出可见历史，也不会回到独立失败入口。名称保持黑色，旁边以灰色“未完成”、绿色“✓ 已完成”、琥珀色“待核对”、红色“错误”和灰色“已恢复”标明当前状态；回收站显示蓝灰色“回收站”并复用垃圾桶图标，已取消与已移除分别显示实际结果，不使用笼统的“已核对”或“进行中”标签。通知在名称前复用浅灰“通知”标签并缩小适配，名称后统一显示未完成 / 已完成，阅读状态仍复用任务完成状态。任务状态随工作区更新，候选确认后显示对应任务的状态并可打开任务，批次分类数量仍表示当时的导入结果；人工核对结果保留在核对分类，新增只记录自动保存的新增结果。原文只有日期时，具体时刻可留空。

人工核对时明确确认新增、更新、延期或取消的动作和目标任务，以点击“确认加入任务 / 确认保存 / 确认取消任务”表示确认，不再额外勾选“我已核对原文和变更”；提交仍检查候选及任务版本。失败保留成功结果并提供重试；账号变化后，旧请求不能把原账号的结果写回页面。


## 详情、账号与保存

账号摘要在昵称、邮箱与验证状态左侧显示 72px 圆形头像，未上传时使用昵称首字；平时只显示头像，悬停或键盘聚焦时覆盖半透明灰色遮罩与“更改头像”，不显示相机图标。手机直接点击头像打开编辑窗口，支持 JPG/PNG/WebP（5 MB 内）、圆形预览、缩放和水平/垂直裁切、取消及恢复默认。保存成功同步侧栏并在刷新、重新登录后保留；失败保留原头像和当前预览供重试。

待核对候选也以任务行出现在清单中，使用黄色“待核对”标签，保留普通任务的完成勾选，点击标题打开普通详情与编辑器，行尾提供“忽略”，成功后可通过提示撤销。新增候选按当前标题、课程、来源及明确日期参与搜索、筛选、分组和侧栏计数；待核对通知进入通知清单，未确认或推断日期显示“日期待核对”并放在无日期分组。候选在主动操作前仅作为展示投影。用户直接勾选完成时，同一事务保存为已完成任务并移除待核对状态；编辑标题、课程、说明、类型或日期并成功保存实际修改时，保存为普通未完成任务并移除标记。仅查看、取消、未修改字段及保存失败保留标记；重新打开完成任务不恢复待核对状态。日历继续展示已确认记录。修改、延期和取消仅在具有明确目标任务身份时挂在原任务下方，标为“待核对变更”，原字段保持不变；目标不明确时保留独立变更候选，不按标题猜测关联。忽略、撤销及确认复用原有版本校验与接口，导入页和清单共用候选状态，失败保留内容并提供重试。

详情抽屉集中展示名称、日期、课程、来源、说明和原文依据；任务显示截止与完成状态，通知显示关键时间、类型和阅读状态，并提供“已阅读”复选框。列表阅读按钮与详情入口独立，操作后同步清单、详情和侧栏计数；保存失败沿用重试入口，不报告保存成功。编辑字段保持简洁，说明与课程可不填；只有时刻而没有日期的输入不能保存。编辑可选择任务或通知，保存内容类型和状态；候选更新已有记录透传目标记录的内容类型。完成、阅读和编辑操作保留浏览上下文，关闭后回到合理的任务或日期位置。

账号弹窗在昵称和密码操作下方提供紧凑的“教学网账号”管理栏，直接复用导入页的连接、更新和移除表单。尚未打开导入页时按需读取已保存账号，不回填密码；读取期间关闭或切换窗口后，迟到响应不得重新打开窗口。账号弹窗保留主动使用反馈，连续次日使用时可出现一次可关闭的非阻塞评分，不替换任务编辑器。1～5 分在手机和桌面始终等宽同排，颜色从红、橙、黄、黄绿过渡到绿；选中后加深背景和边框。选择后可继续改分，提示随分数变化并保留反馈草稿；请求按点击顺序保存，同一账号只保留最后一次评分。原窗口提供选填输入框及“提交反馈”“暂时跳过”，不另显示“使用反馈（选填）”标题；跳过保留评分；跳过、仅提交评分和提交评论成功后统一显示“谢谢您的反馈，我们会继续努力！”，并在 1.5 秒内收起，失败保留输入并允许重试。浮层弹出及收起采用短暂淡入淡出和位移动画，减少动态效果偏好下省略动画。管理员后台使用独立入口和登录，不放入普通导航；合成预览不记录访问或提供反馈提交。

新账号注册增加六位邮箱验证码；发送成功显示有效期和重发倒计时，发送及校验失败保留昵称、密码和可重试状态，修改邮箱时清除原验证码。已有账号未验证时保留使用权限，侧栏与账号面板提示补验证当前邮箱，验证成功不重置任务或保存队列。发送中关闭、切换账号后的旧响应不改变新界面；尚不提供换绑邮箱。这里的账号验证与尚未接入的邮件内容导入分别处理。

匿名登录面板左下角提供“忘记密码”，登录和注册按钮靠右：使用已验证账号邮箱获取独立用途验证码，输入新密码及确认密码后重置，成功返回登录并提示重新登录。发码提示不区分邮箱是否存在或具备找回资格；失败保留输入，修改邮箱清除旧挑战，关闭或切换账号后忽略迟到结果。已有账号未验证且忘记密码时不能绕过验证取得账号。

弹窗与任务抽屉仅在按下及松开都发生在外部遮罩时关闭；从内部拖到外部松开保留窗口和输入内容。关闭按钮与 Esc 沿用现有行为，指针取消或窗口关闭时清理本次遮罩手势状态。

删除进入回收站，提供即时撤销；任务页底部可打开已有回收站记录并恢复。账号入口固定在侧栏底部，保存状态和连接错误清楚可见；登录、退出或切换账号清理旧任务、编辑与撤销上下文。

前端只管理任务和回收站，不包含历史任务迁移、课程资料工作区或旧学习时段的转换。来源证据由接口读取；账号请求隔离、保存队列、冲突提示、删除撤销与恢复保留。服务端任务接口仍要求 `plans`、`subtasks` 数组，新任务提交空数组，已有字段直接透传，不提供对应编辑能力。

- [Todoist 快捷键与侧栏](https://www.todoist.com/help/todoist/features/use-keyboard-shortcuts-in-todoist-Wyovn2)：导航折叠和键盘可达性。
- [滴答清单月视图](https://help.dida365.com/articles/6950640298334617600)、[周视图](https://help.dida365.com/articles/6950641140068515840)：时间范围切换、日期概览与按天查询。
