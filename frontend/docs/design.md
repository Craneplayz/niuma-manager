# 当前界面规格

## 产品范围

HTTPS 和 localhost 的普通任务先在同源浏览器中按账号加密暂存单条操作，暂存成功才更新列表；暂存失败保留编辑器草稿并提示，不声称已经修改。刷新、关页或进程退出后先核对服务器回执，再继续尚未完成的操作；离页提醒保留。网络未恢复时“重新连接”不会丢弃暂存；冲突时“重新读取”明确提示将放弃本页待保存的修改。密码、附件和整个工作区不写入本地队列，清理及安全边界见 [保存接口](../../contracts/docs/task-writes-v0.1.md)。

普通 HTTP IP 入口继续支持在线任务操作，等待服务器确认后才更新界面，不在本地保存操作正文；页面提示保存完成后再刷新或关闭，网络失败可在当前页面重试。HTTPS 与 localhost 保留加密暂存和刷新恢复，安全入口存储失败时不降级写入。

主界面突出任务内容，功能入口集中且容易点击。两条主要路径是“导入通知”和“查看、处理任务”；不在主页面增加统计卡片、宣传文案或其他工作台。

导入来源包括文本、教学网和图片与文件。邮箱保留显式禁用入口，尚未接入。任务支持新增、编辑、完成、重新打开、删除到回收站和恢复；账号位于侧栏底部。当前不提供学习规划、任务拆分、时段安排或计时功能。

安全入口的普通任务新增、编辑、完成、删除和恢复立即更新列表，编辑提交和删除后立即返回列表；后台按操作顺序保存，只暂时限制同一条任务的重复修改，仍可查看详情、关闭抽屉并处理其他任务。成功回执与撤销只在服务器确认后出现；保存失败保留待保存操作并暂停继续修改，提供重试，版本冲突须重新读取。

真实数据属于登录账号并保存到服务端。`demo=1` 只展示合成任务：操作留在页面内存，刷新重置，文本和任务不发送到识别、采集或账号保存接口。视图偏好可以保存在浏览器，公开环境信息可以读取。

## 视觉原则

系统错误说明面向普通用户，说明未完成的操作和用户可执行的下一步，不要求安装依赖、配置模型或理解协议。统一错误区提供“反馈此问题”，仅点击后提交受限分类、操作、时间和版本，显示提交中、已提交或可重试的失败；未知错误保留通用提示和反馈入口。普通输入校验直接提示更正，不作为系统错误上报。弹窗中的错误与反馈按钮必须在弹窗内可操作，不用短暂消失的提示替代；反馈不得清空编辑内容。服务器不可用时如实显示未能确认提交。

通知使用独立入口、浅灰标签和日历中的灰色卡片。列表左侧与详情底部都可勾选“已阅读”，取消勾选恢复未阅读，两处状态同步。读取既有 `content_type`；阅读状态复用任务状态，通知的 completed / done 表示已阅读，其他可见状态表示未阅读，不新增接口字段或执行历史数据迁移。

界面采用克制的卡通风格：内容与侧栏保持纯白，沿用清楚的文字层级和留白，以细描边、圆润控件和少量牛马形象建立辨识度。主按钮使用柔和珊瑚桃色与深棕文字，导航、视图开关和账号入口悬停使用同一浅桃色；日期保留雾蓝，错误、逾期和恢复结果沿用各自语义颜色。

60 / 30 / 10 是面积与视觉权重的指导：主要内容约占六成，功能区域和次层信息约占三成，关键操作与选中态约占一成。它不要求给三块区域分别涂满颜色，也不要求强行增加蓝色面积；先保证内容、导航、操作的层级，再按实际页面调整留白。

| 层级 | 表现 |
| --- | --- |
| 主要内容 | 白色任务区域，最清晰的正文对比与主要阅读空间 |
| 功能区域 | 白色侧栏、细分隔线和少量中性控件底色，导航和任务内容明确分开 |
| 主操作 | 珊瑚桃色按钮、深棕文字、简短动词和可识别图标；停止导入保持深色白字 |
| 选中与日期 | 导航与视图开关使用浅桃色，日期保留雾蓝，使用形状与字重共同区分 |
| 辅助信息 | 中灰文字，字号降低但保持清楚可读 |

桌面页面标题为 29px，导入与任务复用紧凑标题组件。各页统一移除“我的任务 / 通知 / 导入”等浅色辅助标注及其独立占位行，让正式标题与正文整体上移。日期与标题同处首行右侧；有“添加任务”入口时，按钮位于日期左侧，间隔 16px，二者整体靠右。任务名称约 17–18px、当日面板任务约 15px、课程和来源约 11–12px。层级同时依靠字号、字重、位置和留白；不以浅到难读的颜色区分信息。任务名称允许自然换行，避免为了容纳冗长标签压缩正文。

按钮和输入控件沿用 12px 主圆角与细边框，主按钮的深棕文字保持清楚对比；清单、日历、导入、详情、账号和独立后台共用主题颜色与控件层级。任务保持平铺，日期分组以细线分隔，正文区域保留完整阅读空间。

品牌图采用单体扫描牛：右上为空心勾选牛角，下方是单点与直线进度嘴，扫描框仅保留左上与右下两个对角。普通应用、后台顶栏与后台登录使用同一 `brand-logo.webp`，标签页图标由 `favicon.svg` 嵌入该图生成；仅裁去多余白边并缩小，不重绘形象。

主界面品牌图显示为 36×32px，窄桌面侧栏使用 32×28px；展开侧栏底部保留 156×84px 探头形象。图片预留固定尺寸，不独立接收指针或键盘焦点。折叠侧栏隐藏品牌图与底部插画；700px 及以下手机宽度或 720px 及以下窗口高度隐藏底部插画，优先保留导航和账号入口。

`theme.css` 统一维护品牌深棕 `#4a291c`、主操作珊瑚桃 `#f2a18a`、悬停 `#eb957e`、按下 `#e48970`、浅底 `#fff1ec` 与边框 `#f0d1c7`；操作文字使用 `#9c4935`，焦点轮廓使用 `#a44f3a`。正文、中性分隔线与语义色沿用原有层级。

## 布局与入口

- 桌面固定收放按钮切换 232px 侧栏与 72px 图标栏；折叠后可直接点击导入、全部任务、通知、临近截止、已完成和账号，悬停约 500ms 或键盘聚焦时显示名称。导入为明显主入口，任务范围位于同一区域，账号固定底部。
- 所有页面位于 `app.js` 统一的 `.page-frame` 内，最大宽度 1450px；共用标题栏包含正式标题、视图切换、操作和日期，清单与日历切换时标题位置保持一致，日历省略查询行以留出阅读空间。
- 清单、日历和导入正文共用 `.page-frame` 的左右边界；后续页面共用 `workspaceHeading` 提供的导航与日期，并通过 `renderPageHeading` 和 `.page-frame` 统一布局，仅在内部调整阅读区或宽视图。
- 任务详情采用约 420px 的右侧抽屉，背景清单和查询状态保留。
- 700px 为手机布局断点：侧栏保持可关闭的抽屉菜单，不使用桌面图标栏；首行左侧保留导航触发按钮，右侧排列添加按钮与日期，间隔 12px。正式标题与视图切换在次行，任务抽屉适配窄屏。
- 关键触控操作提供至少 44px 有效点击高度。选中状态除了颜色，还使用字重、形状及 `aria-pressed` 或 `aria-current`。

“清单 / 日历”双段开关放在全部任务标题右侧，删除独立标签栏；临近截止与已完成固定使用清单。“月 / 周”只出现在日历内部，避免把所有视图放进侧栏。日期选择和查询控件不与导入入口争夺视觉重点。

## 任务查询与清单

侧栏依次提供全部任务、通知、临近截止、已完成。全部任务清单显示未完成任务；通知清单保留有日期和无日期、未阅读和已阅读的通知，已阅读项保持勾选，方便直接取消。临近截止包含逾期和今天起未来 7 天的未完成任务及未阅读通知；已完成混合展示已完成任务和已阅读通知，相应计数包含两类内容。通知使用浅灰“通知”标签和阅读勾选，关键时间与任务截止分开表述；沿用查询、详情、编辑、回收站和撤销操作。

任务清单按以下顺序分组，空组不显示：已逾期、今天截止、明天截止、未来 7 天、之后截止、无截止日期。清单与日历共用截止判断。已确认的未完成任务到达明确的截止分钟即进入“已逾期”，仅给出日期的任务到次日才逾期。页面保持打开时自动更新，重新回到页面时也会校准。任务与通知混合时，逾期组含今天到点的任务则标为“时间已过”，只含之前日期时标为“早于今天”。未阅读通知的过去关键日期使用红色，已阅读后恢复普通颜色。通知清单与已完成清单平铺，已阅读通知不使用任务的删除线。

通知清单优先显示未阅读通知，已阅读通知放在下方；同一阅读状态内按关键时间从早到晚排列：先比较日期，同一天按具体时刻升序，仅有日期的通知排在当天有时刻的通知之后；无有效日期的通知放在最后。相同时间按稳定 ID 排序；搜索、筛选和更新阅读状态后继续沿用此规则。排序只作用于前端展示，不改写服务端数据顺序。

清单查询区常驻关键词、课程和筛选入口，来源与截止日期范围通过浮层覆盖在清单上方，组合条件一起生效。切换到日历时不绘制查询及高级筛选区，也不应用清单条件，防止隐藏筛选造成日程缺漏；切回清单恢复原查询条件。完成任务或关闭详情保留查询、选中日期和浏览范围；从日历进入临近截止或已完成，再返回全部任务时，恢复原月份、日期、月周模式与视图偏好。

任务行的完成按钮与详情按钮相互独立，不能嵌套按钮。名称是视觉主体，课程、来源与进行中状态退到辅助层；截止日期在清楚的位置显示。查看详情后可编辑任务、标记完成或删除。

课程使用 8 个固定柔和色系，清单和当日面板将课程名显示为“同色圆点＋浅底课程签”，详情复用同一课程签，已选课程筛选旁显示同色点；未填写课程时使用中性灰“未分类”。任务标题保持深色，来源仍为辅助灰字；课程名始终保留，长名可截断但完整名称可查看，避免只靠颜色区分。

配色依据规范化课程名识别，已有课程保持原色，新课程优先使用空余色；超过 8 门允许复用色系。浏览器按账号范围保存课程名哈希和色号的视觉偏好，不保存课程名原文或任务；存储不可用时继续显示可用配色，不阻断任务操作。更名后的课程按新名称识别；当前不增加选色设置或自定义筛选器。课程色与逾期红等状态色各自表达含义，不改变日期雾蓝和页面白底。

任务页的「＋」打开紧凑的单句输入框。可识别的日期和时刻在原句内显示桃色，下方同步给出日期和分类，点击可以校正。确认「添加」或按回车才保存；中文输入法选择候选词的回车留给输入法处理。新任务在当前清单或所选日程中短暂高亮，现有筛选会隐藏结果时单独显示刚添加的任务，保留筛选条件。

## 任务批量操作

清单查询区提供“批量操作”，进入后用方形选择框替换行左侧的完成按钮，名称仍可打开详情；原按钮切换为“退出批量操作”，下方操作栏显示已选数量、全选筛选结果和可执行操作。全选仅包含当前分类与筛选结果中的任务和通知；后来导入的内容不自动选中。调整查询、课程、来源、日期范围，切换分类、视图、导航或账号时清空选择；选择不写入网址和本地偏好。

批量完成、重新打开、修改日期、删除使用明确的目标状态，通知称为已阅读或未阅读；混合内容同时注明两种含义，不逐项反转。修改日期只输入日期，保留各项原时刻；留空同时清除日期与时刻。回收站提供独立多选与批量恢复。

桌面使用清单上方的紧凑操作栏；手机将操作栏固定在底部，内容与提示留出空间，控件至少 44px，320px 宽度不横向溢出。保存期间只锁本批内容，其他任务仍可查看和编辑；服务端整批成功后更新清单并提供 7 秒撤销，失败保留选择和明确错误。无法确认保存结果时沿用页面“重试保存”，重新核对原操作回执，不创建第二批。撤销不覆盖后续修改。

## 月历与周历

日历仅属于全部任务页，展示未完成任务的**截止日期**及通知的**关键时间**，不表示执行时段或学习计划；已完成任务不进入截止摘要，完成记录另按实际完成日显示。通知以灰色卡片和“通知”标签区分，不额外展示类型图例或通知总数，通知不计入任务总数。具体时刻可以展示；未提供时刻时不补造 23:59。

每个日期格只显示一种底色，按逾期亮红、待完成亮蓝、已完成亮绿的顺序决定；没有任务记录时保留白色。浓淡只看决定底色的类别数量，不叠加其他类别：例如当天完成 8 项、待办 5 项、逾期 1 项，显示 1 项逾期的浅红色。固定数量档位为 1、2–3、4–6、7 及以上，背景不透明度分别为 10%、18%、26%、34%，数字与文字不随底色变透明；翻月份不改变数量映射。完成按实际 `completedAt` 日期计入，其余按截止日；今天有明确截止时刻且已经到时的未完成任务计为逾期，无具体时刻仍属待完成，不补造时间。

活动只汇总已保存的任务，排除通知、回收站及取消的任务；无截止日期的未完成任务保留在无日期面板，无有效完成日期的旧任务不补造完成日。记录依据当前保存状态计算，重新打开、完成、撤销和跨日后更新，不新增独立历史事件或统计存储。完成日沿用已保存的日期原值：手动操作为设备本地日，后台自动完成为北京时间日期，不在展示时重新换算。

点击日期后显示当天全部截止任务、通知和实际完成记录，沿用原有日期选择和任务详情操作。当日面板按原排序展示“截止与通知”和“这天完成”，未完成任务、通知仍可查看、拖动和改期；选中日期随网址恢复。清单搜索与课程筛选不影响日历记录，月、周沿用同一口径。有色格局部加深辅助文字，跨月有色格保持文字不透明，任务控件继续可读。明确截止时刻到达时自动更新底色，不刷新页面或发起任务写入。

月历周一开头，按月份显示 4–6 行并淡化相邻月份日期，按标题、工具栏及活动图例下方的可用窗口高度等分行高，优先在首屏展示完整月份。日期沿用原有按钮，点击查看当天全部内容，保持至少 44px 的有效点击高度；空间充足时最多显示两条任务摘要，更多任务用“+N 项”进入当天清单，行高变小时缩为首条摘要与数量，88px 以下优先保留日期和底色，完整内容及数量仍可在当日面板查看。今天和选中日期以轻背景或小圆区分，桌面摘要可直接打开任务详情；极矮窗口允许自然滚动，不裁掉日期或任务。

在手机上点月历或周历中的日期后，当天详情滚入视野。详情顶部列出所选周的七个日期，可以轻点、横滑或用左右方向键切日，也可以用箭头移到前后周的同一天。点年月返回所选日所在的完整月份。“添加到这天”带入正在查看的日期，输入其他明确日期时以输入为准。

周视图按周一至周日列出截止任务，不使用小时网格。月、周支持前后导航、返回今天及指定日期跳转；月份和周范围正确跨年。进入周视图应围绕当前选中日期展示，避免日历与当日面板指向不同时间。

月历与周历任务摘要使用同色圆点和课程简称，完整课程名在提示与辅助阅读名称中保留。宽屏当日任务在日历右侧独立滚动，窄屏在完整月历下方。无日期任务有明确入口，不塞进任何日期格。手机月历隐藏长标题，保留日期、任务数量与最多 3 个去重课程色点，点击后在下方阅读完整课程签和清单；手机周视图改为按天的单列列表，避免横向滚动。

月、周视图的日期格、当日任务和“无日期”面板均支持拖动未完成任务和未阅读通知；单击仍打开详情；鼠标主键按住任务名称并移动至少 6px 后才开始拖动，不新增设置日期按钮。拖动预览按任务文字中的抓取位置贴住鼠标，指针覆盖文字，不再向右下偏移；从课程、来源等辅助区域起拖时使用文字中心。整格日期都可接收任务，悬停高亮并预告目标截止日期；松开后设置或更改截止日期，无日期任务按日期精度保存，已有日期的任务保留原时刻；拖回原日期不重复保存。保存成功后任务移入目标日期格并选中该日，保留当前面板以便继续整理，并提供 7 秒撤销；明确拒绝的拖放留在原位且不会重试；超时、断网或服务异常无法确定是否已保存时保留操作，重试先核对回执，版本冲突须重新读取。拖到日期外、Esc、指针取消、失焦或页面重绘均取消操作，拖放结束不触发详情。通知沿用相同拖动、保留时刻及撤销逻辑，提示称为关键日期；已完成任务、已阅读通知不可拖动，触屏滚动沿用现有行为；键盘与手机可通过原有详情编辑日期。

编辑过程中如果任务内容被更新或移除，保存时保留草稿并提示重新核对；临时保存失败后可再次保存。删除或恢复失败后，“重试保存”会重试原操作并同步任务与回收站列表。

## 导入

文本通知从任务页的加号导入。教学网页保留连接状态和连接管理，同一操作区选择单次、定时频率或自定义间隔，并使用一个主按钮启动识别或停止定时同步；仅在选择待启动的定时频率后展示明确授权。邮箱入口禁用并明确说明尚未接入。

教学网在后台采集、识别并保存任务和通知。进度和已保存结果可在刷新后恢复。停止按钮会阻止后续派发，保留已经保存的任务。历史中的“处理未完成”只重试失败的来源。

分类标签显示本次导入的历史数量。错误按恢复进度显示红、黄或绿色，已恢复的错误可跳转到后续批次。

未解决的错误排在最前，已恢复的错误排在最后。排序变化保留当前展开的分类。

点击灰色“已恢复”时，沿恢复链接展开全部关联批次及其历史分类，将第一处关联批次的完整标题滚动到可视区域顶部并留 24px 间距；所有关联条目使用浅色背景和蓝灰色左边线高亮，保留原状态颜色，不追加箭头或文字标记。靠近页尾时临时补足滚动空间；高亮在滚动、键盘浏览及重绘后保留，切换分类、查看其他恢复记录、收起历史或离开导入页时清除。读取期间的后续操作仍取消迟到定位，整轮恢复包括首次成功采集的全部产出及后续分批重试结果；旧记录缺少具体名称或没有产出时定位并高亮批次标题；目标不在最近 20 条时读取单批次；对应记录不存在时提示“对应的恢复记录已无法查看，已保存的任务不受影响”，读取暂时失败时提示稍后重试。

文本识别仍使用当前页面请求，“停止导入”取消等待及后续前端处理；点击后说明后台已开始的识别可能继续，按钮旁不常驻说明。自动同步使用 source-sync/0.1 的现有接口；频率选择提供单次、常用间隔与 15～10080 分钟自定义间隔，定时启动时须明确同意定期获取与识别教学网内容，并立即识别一次；切回单次会先关闭已有定时服务。点击停止同步后保留当前选中的频率及自定义分钟数，按钮回到待启动状态；重新启动沿用既有明确授权流程。未连接账号、服务未开放或保存冲突均提供对应状态。前端不提供任务排程入口。

图片与附件可通过任务页的加号选择，电脑上也可拖入输入框。处理结果直接出现在清单中。

教学网页不再提供“作业与提交状态”手动目录和管理弹窗；后台原生提交识别、已有提交关联及自动完成逻辑保留。

导入历史按批次展示已保存的任务、通知和错误。旧回执中的条目归入“历史记录”，可打开当前仍存在的任务。



## 详情、账号与保存

首次打开清单、日历或侧栏时，从同一份工作区读取已保存的任务和通知。

识别期间允许编辑下一段通知草稿；提交快照与编辑草稿分别保存，迟到回执不得清空新草稿，仍一次识别一段且不自动提交。文本与文件输入不等待教学网账号读取。后台进度与结果变化保留当前输入、组合输入、展开内容和阅读位置；任务详情中的状态变化复用原文，不重新加载或折叠已打开的证据。

账号摘要在昵称、邮箱与验证状态左侧显示 72px 圆形头像，未上传时使用昵称首字；平时只显示头像，悬停或键盘聚焦时覆盖半透明灰色遮罩与“更改头像”，不显示相机图标。手机直接点击头像打开编辑窗口，支持 JPG/PNG/WebP（5 MB 内）、圆形预览、缩放和水平/垂直裁切、取消及恢复默认。保存成功同步侧栏并在刷新、重新登录后保留；失败保留原头像和当前预览供重试。

识别出延期、修改或取消时，系统保存一条普通通知。用户可以在通知详情中选择原任务，打开编辑器并按需保存。

详情抽屉集中展示名称、日期、课程、来源、说明和原文依据；任务显示截止与完成状态，通知显示关键时间、类型和阅读状态，并提供“已阅读”复选框。列表阅读按钮与详情入口独立，操作后同步清单、详情和侧栏计数；保存失败沿用重试入口，不报告保存成功。编辑字段保持简洁，说明与课程可不填；只有时刻而没有日期的输入不能保存。编辑可选择任务或通知，保存内容类型和状态。完成、阅读和编辑操作保留浏览上下文，关闭后回到合理的任务或日期位置。

账号弹窗在昵称和密码操作下方提供紧凑的“教学网账号”管理栏，直接复用导入页的连接、更新和移除表单。尚未打开导入页时按需读取已保存账号，不回填密码；读取期间关闭或切换窗口后，迟到响应不得重新打开窗口。账号弹窗保留主动使用反馈，连续次日使用时可出现一次可关闭的非阻塞评分，不替换任务编辑器。1～5 分在手机和桌面始终等宽同排，颜色从红、橙、黄、黄绿过渡到绿；选中后加深背景和边框。选择后可继续改分，提示随分数变化并保留反馈草稿；请求按点击顺序保存，同一账号只保留最后一次评分。原窗口提供选填输入框及“提交反馈”“暂时跳过”，不另显示“使用反馈（选填）”标题；跳过保留评分；跳过、仅提交评分和提交评论成功后统一显示“谢谢您的反馈，我们会继续努力！”，并在 1.5 秒内收起，失败保留输入并允许重试。浮层弹出及收起采用短暂淡入淡出和位移动画，减少动态效果偏好下省略动画。管理员后台使用独立入口和登录，不放入普通导航；合成预览不记录访问或提供反馈提交。

新账号注册增加六位邮箱验证码；发送成功显示有效期和重发倒计时，发送及校验失败保留昵称、密码和可重试状态，修改邮箱时清除原验证码。已有账号未验证时保留使用权限，侧栏与账号面板提示补验证当前邮箱，验证成功不重置任务或保存队列。发送中关闭、切换账号后的旧响应不改变新界面；尚不提供换绑邮箱。这里的账号验证与尚未接入的邮件内容导入分别处理。

匿名登录面板左下角提供“忘记密码”，登录和注册按钮靠右：使用已验证账号邮箱获取独立用途验证码，输入新密码及确认密码后重置，成功返回登录并提示重新登录。发码提示不区分邮箱是否存在或具备找回资格；失败保留输入，修改邮箱清除旧挑战，关闭或切换账号后忽略迟到结果。已有账号未验证且忘记密码时不能绕过验证取得账号。

弹窗与任务抽屉仅在按下及松开都发生在外部遮罩时关闭；从内部拖到外部松开保留窗口和输入内容。关闭按钮与 Esc 沿用现有行为，指针取消或窗口关闭时清理本次遮罩手势状态。

删除进入回收站，提供即时撤销；任务页底部可打开已有回收站记录并恢复。账号入口固定在侧栏底部，保存状态和连接错误清楚可见；登录、退出或切换账号清理旧任务、编辑与撤销上下文。

前端只管理任务和回收站，不包含历史任务迁移、课程资料工作区或旧学习时段的转换。来源证据由接口读取；账号请求隔离、保存队列、冲突提示、删除撤销与恢复保留。服务端任务接口仍要求 `plans`、`subtasks` 数组，新任务提交空数组，已有字段直接透传，不提供对应编辑能力。
