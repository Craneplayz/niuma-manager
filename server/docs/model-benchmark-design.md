## 研究问题与分层样本

问题是“在本系统的既有接口和时间预算下，哪些七牛端点能可靠完成各项业务、代价多少”，不是通用智能排名。

保留原28例作历史回归，新增分层测试版本；历史与新版本分开，不将重复、改名或同一原件衍生例计成独立来源。每例记录case_id、family_id、module、scenario、difficulty、risk、origin、预期字段及明确人工判定项；先冻结参考标签和文件哈希，再调用模型。

- M1文字：任务/非任务；明确阅读与普通课件标题；无DDL但有行动；活动时间/DDL；日期精度、相对日期、周次、年界；多个任务；改期/取消；冲突、正文不全、指令干扰与长文本。
- M1视觉：日期6/9、日期/时刻、无日期、负例、多行动、排版噪声、低对比度/旋转；同内容文字对照单列，避免把OCR和任务推理混成一种失败。
- M2拆解：原子动作、真实未知作业、明确必需交付物、用户显式剩余工作、已完成步骤、依赖、无依据要求、结构化信息不足；不假定教学网含个人进度。明确动作覆盖只用于确有参考动作的例。
- M3任务工时：ID齐全/多任务、有限正数、明确时长、显式剩余进度、改名/噪声不变性、边界单位、信息稀缺；无真实完成标签时不计算“真实准确率”。模型运行时间与任务工时分列。
- 成对变换：日期改变应改变对应字段；噪声/名字改变不应改变明确工时；增加明确剩余工作只影响相应任务；缺少证据应保留未知。按family报告，不夸大独立样本量。
- 稳定性：固定哨兵集至少3次独立调用，重复编号独立保存；统计全次通过/至少一次失败及分布，不把缓存读回当重复实验。
- 真实材料：从已授权私有教学网样本按场景分层，原文/附件状态保留；仅标题且附件未读标不可判定。公开页面只放去身份概述，原文不复制进公共数据或发往未经确认的其他提供商。

## 预算优先级（用户最新确认）

本轮100元优先保障完整分层样本及预定重复次数。各家先做少量能力/价格探测，再据此选择可完整跑完的模型集合；预计超预算时减少正式参测模型，不删样例、不只留下容易题、不减少预定重复。所有正式参测模型使用相同冻结测试集；探测结果单列，未完整参测者不进入全量排行榜。实际运行发生异常支出而中断时标记部分完成，不将不等覆盖率的模型直接排名。

指标报告给出定义、数值、分子/分母、缺测和区间，而不是只说“几个通过”。任务检出使用对象级Precision/Recall/F1；字段、幻觉、拆解和工时约束分别计算，重复和变换按family聚合后报告稳定性及区间。时间给出P50/P90/P95/max，费用未知不补零。

## 公平设置与执行顺序

DeepSeek、Qwen作现有基线；补Kimi、GPT、Claude、Gemini、Doubao、GLM，各家选择实际可用且价格明确的具体ID。能力不支持时显示不适用；目录缺失、鉴权失败、额度不足、协议不兼容和模型任务失败分别记录。

1. 无计费的目录/配置/价格核对，生成完整实验计划和上限估算。
2. 小样本能力探测，确认JSON、图像及思考参数是否支持；不得把探测失败静默改名后混入正式结果。
3. 用户确认费用粗估后，按整模型矩阵执行同一冻结样本，固定提示词与数据、输出上限、单次与整例时限；记录不可关闭思考和默认参数差异，分设置比较。
4. 哨兵重复和成对变换随主矩阵执行。使用已有回执和价格目录一次粗估，费用估算本身不新增模型调用；全部真实请求含失败/修复均纳入 100 元本轮预算。
5. 运行自动契约和字段断言，保留逐例人工语义复核位；独立留出在选型冻结后运行，不回调主集标签。
6. 离线汇总，发布只读管理员报告；页面不在打开时自动调用模型。

请求发出前持久化在途标记并预占费用，崩溃/未知usage保留预占并停止自动补发；中断后需显式复核。预算账本跨模型/重启共享，不能通过新建输出目录重置100元限制；没有价格依据的端点不进入批量计费。

## 指标与分母

| 维度 | 指标 |
| --- | --- |
| 完整性 | 计划/已执行/已完成/待执行/不可用/不适用；独立family、来源数与重复数 |
| 正确性 | 契约成功率；任务Precision/Recall/F1；字段完整率；日期值/精度/角色；无依据行动/日期；M2必要动作覆盖、虚构要求、重复完成、依赖合法、可用计划；M3 ID、有限正分钟及约束遵守 |
| 稳定性 | 重复全通过率、逐例通过波动、变换关系遵守；样本数和Wilson区间。区间为固定集描述，不声称总体泛化 |
| 时间 | 每次请求与整例耗时P50/P90/P95/max、超时率；排队/模型/校验阶段；若无流式观测，TTFT显示未测，不能用总耗时冒充 |
| Token | 实际输入/输出/总量、缓存/思考可用字段、每成功任务Token、缺usage次数；供应商native tokens不可直接解释为同等工作量 |
| 费用 | 输入/输出/缓存单价及币种、标准价估算、每例/每成功例费用、失败/修复费用、预算预占/已知消耗/未知消耗；账单对账独立标明 |
| 错误 | 配置/鉴权/目录、HTTP429/5xx、超时、无效JSON、契约/证据、语义、存储/中断；失败保留分母，非适用不混入排名 |

不合成掩盖分项缺陷的任意“智能总分”；按模块的可用输出及关键字段主指标比较，语义待复核明确标记。时间分位数包含失败耗时并提供成功子集；成本/成功例分母为零时显示未知，不给“免费成功”印象。

## 后台页面设计

在`/admin.html`现有“使用数据 / 运行监控”后增加“模型评测”，复用管理员独立会话、颜色、卡片和表格；普通用户看不到入口，接口同样鉴权。

1. 顶部：实验选择、数据/评分/代码版本、运行状态；计划完成覆盖、模型数、累计Token、标准价估算与100元预算。
2. 筛选：模块、场景、来源类型、难度、重复轮次、模型及失败类型；所有图表与导出使用同一筛选条件。
3. 排行榜：模型/端点/设置、已测/适用、主指标/契约率、P50/P95秒、Token、估算人民币、每成功例成本；可排序，缺测显示“—”。
4. 双散点：质量—每成功例成本、质量—P95延迟；点大小表示样本数，颜色表示厂商。悬停/键盘焦点显示数值，支持点选联动，图外有等价数据表。
5. 热力图：模型×场景或指标，格内同时显示比例和分子/分母；不适用、中断、未知与失败有独立样式。
6. 用量与耗时：分布/分位数、输入输出Token堆叠、失败原因条形图；不画没有数据的平滑趋势线。
7. 逐例对照：原文/参考字段（仅可共享材料）、多个模型输出、判定项、错误、耗时/usage/成本、修复调用与来源版本；可筛选“分歧/共同失败/待人工复核”。
8. 运行记录与JSON/CSV导出：保留历史版本，不混历史56回执与新版本主表；不将测试替身数据展示为真实模型结果。

报告从离线评测产物读取；只读接口不接受浏览器提供模型Key或直接付费运行。数据文件仅由受控服务器管理流程发布到各环境独立目录，原始模型日志及私人材料不进入静态网页构建。

## 验证与交付

先在既有服务器隔离环境检查预算/中断、统计分母、报告鉴权、XSS/路径及导出、筛选联动、桌面/390/320px与构建，再测试同一候选的报告导入和真实模型结果。页面与流程完成后更新同一非Draft评测PR及服务器测试演示；正式发布按现有备份和同镜像流程，不混入#225的业务入口改动。
