# 时序 DDL 智能任务规划

一个响应式前端 MVP，用于区分真实截止日期（DDL）与可调整的执行计划，覆盖任务发现、AI 识别审核、任务拆解、日历查看和执行跟踪的核心闭环。

## 本地运行

需要 Node.js 20.19 或更新版本。若使用 nvm，可以先运行 `nvm use`。

```bash
npm ci
npm run dev
```

打开 `http://localhost:1331`。

## 验证与构建

```bash
npm run lint
npm test
npm run build
npm run preview
```

使用仓库中的 `package-lock.json` 与 `npm ci` 安装锁定依赖。生产构建文件输出至 `dist/`，该目录不提交到 Git。

## 当前实现范围

- 今日工作台：今日安排、临近 DDL、待确认数量与快捷入口。
- 日/周/月日历，支持「全部 / 仅 DDL / 仅计划」展示切换。
- 按截止日期或分类浏览任务，查看任务详情、子任务进度与计划。
- 自然语言创建的 AI 预览流程，以及可编辑的结构化任务表单。
- 待确认任务的审核、确认与忽略；确认后同步进入任务和日历。
- 信息来源同步状态、规划偏好、时区和提醒设置界面。

## 账号与独立规划

首次进入先注册本地账号。邮箱与密码用于当前浏览器登录；任务、待确认结果、可用时间按用户分别保存。退出后重新登录可恢复，清除浏览器网站数据会丢失记录。此阶段没有服务器身份认证、跨设备同步或密码找回能力，请勿将本地账号当作生产账号。

先创建或确认主任务及真实 DDL，再点击工作台的「开始规划」。该面板可选择尚无计划的任务、核对工时、设置工作日和每日可用时段，并显示现有安排。点击生成后预览，确认应用才会追加日历时段，不改变真实 DDL。

默认使用本地演示规划器，未调用真实大模型；信息来源同步仍为模拟。将 `.env.example` 复制为 `.env.local` 并配置 `VITE_API_BASE_URL` 后重启，可联调 `POST /planning/proposals`。先由后端团队接通服务器会话认证；本地登录不会自动授权后端接口。不要把模型密钥放入任何 `VITE_*` 变量。

完整的职责、数据结构、已实现契约、后端待实现接口与验收规则见 [后端与 Harness 对齐说明](docs/backend-harness-alignment.md)。
