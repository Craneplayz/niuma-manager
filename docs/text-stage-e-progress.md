## 本轮真实模型限制

网页提交一条合成通知（提交演示报告及加群）进行了两次真实识别尝试，两次均返回 `agent_timeout`，达到当前 HTTP 识别服务的 20 秒处理预算。第二次在允许 API 网络访问的执行环境重启服务后仍超时，不能归因于已确认的单一环境问题。

页面正确显示失败记录，没有把失败显示为无任务，也没有新增正式任务。此前阶段 D 的真实模型联调成功记录仍保留，但本轮没有重新取得真实识别成功结果，不能宣称模型稳定性已验收。

下一步：用单条合成输入诊断供应商响应、Codex 启动耗时与超时预算；如需调整同步等待时间，应同时协调识别服务、账户后端和网页三层超时，不能只延长其中一层。避免无目的地重复付费调用。
