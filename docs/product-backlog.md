# 牛马管理器 Product Backlog

2026-09-28 小组会议（#48）将产品收敛为「一个对话框 + 产品内日历」，功能只保留下面三项；2026-10-01 进一步收敛：教学网先只处理「课程作业」，重点放在作业进来后的排程。旧版 11 项需求见 [archive](archive/2026-09-28-product-backlog.md)。

## 功能

| ID | 功能 | 说明 | 进日历前确认 | 任务 Issue |
| --- | --- | --- | --- | --- |
| F1 | 识别任务 | 用户在对话框输入文字，识别出任务与 DDL | 要：用户在对话框确认后才进日历 | #70 |
| F2 | 按任务安排内容 | 作业进来后**自动产生**排程提案（例：10 号交的报告，建议 6 号写），依到期日期与可用时间安排何时做 | 要：用户确认后才进日历 | #65、#66、#70 |
| F3 | 外部来源处理 | 教学网只爬「课程作业」及其到期日期，微信导入会话文件；识别后直接进日历，标示来源，可删除、修改 | 不用 | #87、#89、#70 |

- 排程规则（预计用时、提前多久、可用时段、撞期时谁先排、排不下怎么办）由 `task_planning/` 负责人决定，每条附上理由，组内确认后实作（#65）。
- 执行顺序：#65 → #66 → #70；#69（减少本机服务）、#89（爬虫只爬课程作业）同时进行。
- 日历以产品内为主，暂不同步外部（Google / ICS）。
