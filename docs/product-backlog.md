# 牛马管理器 Product Backlog

2026-09-28 小组会议（#48）将产品收敛为「一个对话框 + 产品内日历」，功能只保留下面三项。旧版 11 项需求见 [archive](archive/2026-09-28-product-backlog.md)。

## 功能

| ID | 功能 | 说明 | 进日历前确认 | 任务 Issue |
| --- | --- | --- | --- | --- |
| F1 | 识别任务与优先级 | 用户在对话框输入文字，识别出任务、DDL 与优先级 | 要：用户在对话框确认后才进日历 | #65、#67、#70 |
| F2 | 按任务安排内容 | 依任务、DDL、优先级与可用时间，安排何时做、每段做什么 | 要：先预览再确认 | #66、#70 |
| F3 | 外部来源处理 | 教学网爬虫、微信进来的内容识别后直接进日历，标示来源，可删除、修改 | 不用 | #68 |

- 优先级判断规则由 `task_planning/` 负责人提出，每条规则附上理由，组内确认后实作。
- 日历以产品内为主，暂不同步外部（Google / ICS）。
